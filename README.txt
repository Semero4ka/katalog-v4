КАТАЛОГ ОПТОВЫХ ЦЕН — версия 4 (корзина + заявки + накладные для 1С)

СОСТАВ:
  index.html            — приложение целиком (каталог, корзина, заявки, накладная)
  data.js               — прайс (41 категория, 3297 позиций)
  sw.js                 — сервис-воркер (кэш catalog-v4)
  service-worker.js     — дубль sw.js (для совместимости)
  manifest.webmanifest  — настройки установки на телефон
  icon-192.png, icon-512.png — иконки приложения
  img/                  — папка для фото товаров (1.jpg, 2.jpg … по номеру позиции)

УСТАНОВКА НА GITHUB:
  1. Распакуйте архив.
  2. Создайте репозиторий (или откройте существующий) — Add file -> Upload files.
  3. Перетащите ВСЕ файлы из папки (включая папку img и обе иконки). Commit changes.
  4. Settings -> Pages: Source = Deploy from a branch, Branch = main, папка / (root). Save.
  5. Через 1-2 минуты сайт откроется по адресу https://ваш-логин.github.io/имя-репозитория/

ПОСЛЕ ЗАМЕНЫ ФАЙЛОВ: если меняли index.html — поднимите версию кэша в sw.js
(catalog-v4 -> catalog-v5), иначе у клиентов останется старая версия.

ФУНКЦИИ:
  Каталог: поиск (товар, бренд, объём, цена), фильтр по категориям, сортировка,
  ленивая подгрузка, кнопка "+ В корзину" у каждого товара.
  Корзина: изменение количества, удаление, итог; плавающая кнопка с количеством.
  Заявка: имя/организация, телефон (проверка), комментарий; сохраняется в историю.
  НАКЛАДНАЯ: после оформления заявки открывается редактор накладной
  "Реализация товаров" — номер, дата, поставщик, покупатель, количество и единицы
  (кг/шт) правятся прямо в таблице, суммы и итог пересчитываются на лету.
    - ПЕЧАТЬ/PDF — печатная форма в виде квитанции (как на бумажной накладной):
      шапка, таблица, Итого, "В том числе НДС: 0", сумма прописью, подписи.
    - CSV ДЛЯ 1С — файл для загрузки в 1С: колонки Номер; Дата; Поставщик;
      Покупатель; № строки; Товар; Количество (3 знака, как 0,110); Единица;
      Цена; Сумма + строка Итого. В 1С: Файл -> Открыть (или обработка
      "Загрузка данных из табличного документа"), разделитель — точка с запятой.
  Заявки хранятся локально на устройстве. Номер следующей накладной — 35157
  (счётчик сам продолжится после сохранения; номер и дату можно менять вручную).
  Отпустил (ФИО) — заполните один раз, подставится во все следующие накладные.
